# GitSomething 1.0.0-beta.4

One Windows x64 setup EXE installs GitSomething for your Windows account and adds shortcuts. The earlier beta.3 portable release and all previous release assets stay unchanged.

**[Download GitSomething setup](https://github.com/imranelak1/GitSomething/releases/download/v1.0.0-beta.4/GitSomething_1.0.0-beta.4_x64-setup.exe)**, run it, and complete setup. Git, Node.js, and Rust are not needed: the Git engine, interface, and app assets are included. Setup downloads [Microsoft Edge WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) if it is missing, which requires internet access. The installer and application are unsigned.

Preferences and recent repositories use the normal app profile, and GitHub sign-in uses the OS credential store. The application identity stays unchanged from earlier betas.

## Optional usage sharing stays Off by default

**Usage sharing** on Home and **Privacy & usage sharing** in the command menu offer **Off**, **Anonymous usage**, or **Usage with GitHub username**. Signing into GitHub does not opt you in; the named choice includes only the public login after sign-in.

Allowed action counts and app version are shared with GitSomething's maintainers through PostHog in the EU. Repository names, local paths, code, commit messages, tokens, and credentials are excluded, with no session replay. Changes affect future events and do not delete previously shared events. [Analytics details](https://github.com/imranelak1/GitSomething/blob/main/docs/ANALYTICS.md).

## Your Git workflow

This release keeps GitHub **Clone & open**, local repositories, staging, commits, readable diffs, deliberate **Slide to push**, and the explanatory Glass Box. Git operations use libgit2 without spawning Git commands. This release changes the download and installation format, with no new Git or interface features.

## Verify the setup download

The release provides one setup asset. Its SHA-256 is:

```text
0a7887ac2de55ec291b95ab67d00b91ee22e3147ea0dbf377023bea2964a8e10  GitSomething_1.0.0-beta.4_x64-setup.exe
```

Compare it with `Get-FileHash .\GitSomething_1.0.0-beta.4_x64-setup.exe -Algorithm SHA256`. After publication, verify GitHub's immutable release attestation:

```powershell
gh release verify v1.0.0-beta.4 --repo imranelak1/GitSomething
gh release verify-asset v1.0.0-beta.4 .\GitSomething_1.0.0-beta.4_x64-setup.exe --repo imranelak1/GitSomething
```

Release attestation verifies the published digest; it does not add Windows code signing. Manifests and checksum files remain internal build evidence rather than extra public download choices.

## Limits and verification

This beta targets Windows x64. Advanced history mutation, hunk/line staging, three-way merge resolution, worktrees, Git LFS downloads, and submodule initialization remain outside the current implementation. Pull requires a clean fast-forward; partial clone/publication recovery remains manual.

Beta.4 installation, actual shortcut behavior, and packaged runtime verification are pending. Earlier beta results do not establish those outcomes. Missing-runtime provisioning, live private cloning, native picker interaction, provider publication/pushing, and production analytics ingestion need separately recorded evidence. See the [verification records](https://github.com/imranelak1/GitSomething/blob/main/docs/VERIFICATION.md).
