# GitSomething 0.1.0-alpha.1

First Windows preview, prepared October 17, 2026.

GitSomething makes everyday Git work easier to follow: review changes, choose files for a commit, save locally, and slide to push. The Glass Box explains the equivalent Git commands as operations happen.

## Included

- A Home screen with recent local projects, an optional first-use guide, and a searchable GitHub repository list with public/private filters, counts, and sorting.
- A brief startup introduction on each full launch: drawn Git branches, the prompt cat, a rolling wordmark, and a mask lift into Home. Skip it immediately with **Skip intro**, Escape, or Enter; reduced motion goes directly to Home.
- **Sign in with GitHub** using browser approval. The app includes its shared public OAuth identifier; users never register an app or paste a personal access token.
- File-level staging and unstaging, local commits, fetch, push, and fast-forward-only pull, backed by Rust and libgit2.
- Monaco text diffs, separate staged and unstaged versions, filesystem refresh, and a resizable workspace.
- An adjustable Glass Box with guided Git commands, command explanations, and a distinct learning inspector. Scrolling, resizing, and navigation stay out of its transcript.
- Folder-to-cloud publishing: create local history, create a public or private repository, and push the first commit. GitHub uses the connected account; GitLab.com uses an operation-specific token.
- Repository-state guidance and a detached-HEAD rescue branch that preserves working files.
- An original prompt-faced cat with a branching tail: a brief, finite animation on Home and in the welcome guide, static native/OAuth icons, and a reduced-motion alternative. The brand assets include an animated SVG and a standalone logo preview.

## Install

Download `GitSomething_0.1.0-alpha.1_x64-setup.exe` for Windows x64. The installer uses the current user's account. Microsoft Edge WebView2 is required; the installer can download it when missing, which needs an internet connection.

This alpha is **unsigned**. Windows may display an unknown-publisher or SmartScreen warning. Verify that the file came from the intended project release and compare its SHA-256 with `SHA256SUMS.txt` before deciding whether to run it. No macOS, Linux, ARM64, or signed Windows package is included.

`GitSomething_0.1.0-alpha.1_windows-x64.exe` is the application executable for an existing WebView2 installation. It is not an installer and does not install prerequisites or shortcuts.

## Preview boundaries

- Hunk/line staging, three-way conflict resolution, worktrees, submodules, and interactive rebase are not implemented. History drag interactions preview proposed operations without rewriting history. Finish merge/rebase conflicts with another tool.
- Pull only accepts a clean fast-forward. Destructive resets and force pushes are unavailable.
- GitHub rows open repositories on GitHub; they do not clone them. Filtering searches the repositories already loaded, and additional pages load explicitly.
- Provider support is GitHub.com and GitLab.com. GitLab OAuth and self-hosted providers are not included. Organization access still depends on GitHub permissions and policies.
- Text diffs require UTF-8 and are limited to 2 MiB per file. Publishing rejects existing/nested repositories, obvious credential files, individual files above 50 MiB, and scans above 100,000 files; those checks are not a complete secret scanner.
- A failed publish can leave completed local and remote steps in place. Recovery and retries after partial publication are manual.
- Browser previews use explicit demonstration data. Actual filesystem and provider operations require the desktop app.

A packaged Windows candidate verified launch, the inline animated brand mark, production Monaco worker loading, restored GitHub authorization, actual public/private repository loading, filters, search, and sorting. An earlier candidate also verified explicit pagination and connection restoration after restarting. The final rebuilt candidate also verified the finite startup, immediate Escape dismissal, keyboard focus, no navigation replay, and preserved GitHub connection, with no runtime or CSP errors. Automated checks exercise logo motion and reduced-motion behavior, the Git engine, and sign-in/repository contracts; browser provider responses are explicit fixtures.
