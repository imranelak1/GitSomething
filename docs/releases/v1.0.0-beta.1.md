# GitSomething 1.0.0-beta.1

Windows x64 beta preview, released October 17, 2026. This is a prerelease for review, not a stable 1.0 release.

GitSomething brings everyday Git work into a readable workspace: review a diff, choose files for your next commit, save locally, and slide to push. Its Glass Box explains the equivalent Git commands while Rust and libgit2 perform the actual operations.

## In this beta

- **A calmer first project.** Home offers recent local folders, open/publish actions, an optional first-use guide, and an explicitly labeled demo. Purple learning surfaces explain the difference between staging, committing, and sharing.
- **GitHub sign-in and repositories.** Approve access in your browser, then browse accessible public/private repositories with search, loaded counts, visibility filters, sorting, and explicit pagination. Credentials remain in the native backend and operating system credential store; users never register an app or paste a GitHub personal access token.
- **Everyday native Git.** Open a repository, stage or unstage whole files, commit, fetch, push, and pull a clean fast-forward. A file with staged and unstaged changes has separate versions and diffs. Filesystem watching keeps the working view current.
- **Room to review.** Monaco text diffs, resizable panes, a collapsible sidebar, remembered layout, and deliberate slide-to-push controls keep the next action clear.
- **A useful Glass Box.** Read equivalent commands, inspect token explanations, and type supported guided Git commands. Resize the terminal and adjust its text. Navigation, scrolling, resizing, and lesson openings add no transcript noise.
- **Folder to cloud.** Publish an unversioned local folder through validation, initialization, initial commit, hosted repository creation, and first push. GitHub uses the connected account; GitLab.com uses a token for that operation. Choose Public or Private before confirming.
- **Guidance and identity.** Git Guardian identifies repository states and can create a detached-HEAD rescue branch without changing working files. The original prompt cat introduces each full launch with a short skippable animation; reduced motion goes straight to Home. Static native/OAuth icons, animated vector artwork, and an offline logo preview are included.

## Windows package

Use `GitSomething_1.0.0-beta.1_x64-setup.exe` for Windows x64. The NSIS installer targets the current user's account. Microsoft Edge WebView2 is required; installation may need internet access to download that runtime when it is missing.

`GitSomething_1.0.0-beta.1_windows-x64.exe` is the application executable for a machine with WebView2 already installed. It does not install prerequisites or shortcuts. The assets also include `manifest.json`, `SHA256SUMS.txt`, release notes, and the brand exports.

Both executable packages are **unsigned**. Windows may display an unknown-publisher or SmartScreen warning. Check the intended source and compare SHA-256 values with `SHA256SUMS.txt` before deciding whether to run a downloaded file. No signed Windows, macOS, Linux, or ARM64 package is included. This prerelease and its assets are publicly downloadable from GitHub.

## Current limits

- Hunk/line staging, three-way conflict resolution, worktrees, submodules, and interactive rebase are not implemented. History drags preview proposed relationships without rewriting commits. Complete merge/rebase conflicts with another tool.
- Pull requires a clean fast-forward. Destructive resets and force pushes are unavailable.
- GitHub rows open the repository on GitHub; they do not clone it or open a local workspace. Search, visibility counts, and sorting cover loaded repositories, up to 100 per requested page.
- Hosted integration supports GitHub.com and GitLab.com. GitLab OAuth, self-hosted providers, and unrestricted organization access are not included; account permissions and provider policies still apply.
- Text diffs require UTF-8 and are limited to 2 MiB per file. Publishing rejects existing/nested repositories, obvious credential files, individual files above 50 MiB, and scans above 100,000 files. These checks are not a complete secret scanner.
- A failed publication can leave completed local and remote steps in place. Recovery after partial publication is manual.
- Browser previews use demonstration data; real filesystem and provider operations require the desktop app.

## Verification

The newly built **1.0.0-beta.1** Windows executable passed five packaged runtime checks and six native startup checks. It restored the previously approved GitHub connection and loaded 78 accessible repositories; visibility counts, name sorting, search, and clear/focus controls passed without reauthorization. Production Monaco workers and the CSP passed with zero recorded runtime/security errors. No private repository names, URLs, or connected-account screenshots were recorded.

All 73 frontend unit tests, 34 Rust tests, formatting, strict Clippy, and 12 production startup browser groups passed. The production dependency audit reported zero vulnerabilities. Browser provider responses are explicit fixtures. The beta's exact checks, GitHub workflow result, and asset verification are recorded in [VERIFICATION.md](https://github.com/imranelak1/GitSomething/blob/main/docs/VERIFICATION.md).

Installer installation/uninstallation and live GitHub publication/pushing remain unverified. Use an explicitly chosen disposable project for those provider checks before relying on this preview for a new publication.
