# GitSomething 1.0.0-beta.3

A Windows x64 beta with one direct-run EXE and optional usage sharing. Existing releases and their uploaded assets remain unchanged.

**[Download GitSomething](https://github.com/imranelak1/GitSomething/releases/download/v1.0.0-beta.3/GitSomething_1.0.0-beta.3_windows-x64.exe)** and open it directly. No installer or extraction step is needed. [Microsoft Edge WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) must already be installed; Git, Node.js, and Rust are not required. The interface, Git engine, and application assets are bundled.

Preferences and recents use the normal app profile, and sign-in uses the OS credential store, so deleting the portable EXE does not remove that state. The Windows executable is unsigned.

## Optional usage sharing

**Usage sharing** on Home and **Privacy & usage sharing** in the command menu offer three choices: **Off** (the default), **Anonymous usage**, or **Usage with GitHub username**. A GitHub connection by itself does not opt you in. The named choice includes the public username only after sign-in.

Allowed action counts and app version are shared with GitSomething's maintainers through PostHog in the EU. Repository names, local paths, code, commit messages, tokens, and credentials are excluded. There is no session replay. Preference changes affect future events; they do not delete events already shared. [Privacy and implementation details](https://github.com/imranelak1/GitSomething/blob/main/docs/ANALYTICS.md).

## Continue your Git workflow

The release keeps GitHub **Clone & open**, local repository opening, staging, commits, readable diffs, deliberate **Slide to push**, and the explanatory Glass Box. Git operations run through libgit2 without spawning Git commands. Existing beta.2 profiles and OS-stored sign-in use the same application identity.

Compare it with `Get-FileHash .\GitSomething_1.0.0-beta.3_windows-x64.exe -Algorithm SHA256`. After publication, GitHub's immutable release attestation can also be verified:

```powershell
gh release verify v1.0.0-beta.3 --repo imranelak1/GitSomething
gh release verify-asset v1.0.0-beta.3 .\GitSomething_1.0.0-beta.3_windows-x64.exe --repo imranelak1/GitSomething
```

Release attestation does not add a Windows signing signature. Internal packaging manifests and checksum files are build evidence; they are not additional public download assets for this release.

## Current limits and verification

This beta targets Windows x64. It requires an existing WebView2 runtime and includes no installer, macOS, Linux, or ARM64 package. Advanced history mutation, hunk/line staging, three-way merge resolution, worktrees, Git LFS downloads, and submodule initialization remain outside the current implementation. Pull requires a clean fast-forward, and partial clone/publication recovery remains manual.

TypeScript, 90 frontend unit tests, 42 Rust tests, 12 PE-auditor tests, Rust formatting, strict Clippy, and the locked production build passed. The actual beta.3 EXE launched from a folder containing only that file. Native checks confirmed its version, embedded GitHub configuration, branding, bundled Monaco worker, and real local Git branch/history reads, with no runtime or CSP errors. Its 32 normal DLL imports are Windows components; there are no delay imports or third-party DLL imports. Usage sharing remained Off.

This checks the application on a Windows machine with WebView2 already installed; it does not establish a clean-machine or missing-runtime experience. Live private cloning, native picker interaction, provider publication/pushing, and production analytics ingestion remain unverified. [Verification records](https://github.com/imranelak1/GitSomething/blob/main/docs/VERIFICATION.md) distinguish automated fixtures from real native and provider checks.
