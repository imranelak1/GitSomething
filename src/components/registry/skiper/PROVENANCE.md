# Skiper UI integration boundary

Registry home: https://skiper-ui.com/

Registry endpoint pattern: https://skiper-ui.com/registry/{name}.json

Terms inspected October 16, 2026: https://skiper-ui.com/docs/terms-of-service

Skiper UI distributes source through a shadcn registry. It is not a runtime npm package. The current terms reserve rights and restrict redistribution; premium component source requires an appropriate license.

`KineticModal.tsx` is original code authored for this project using Radix Dialog and Framer Motion. Its focus transition and restrained kinetic interaction are inspired by the requested Skiper UI aesthetic. It is **not** a copied, officially installed, or licensed Skiper UI component. No paid registry source is bundled. A user-provided, appropriately licensed Skiper component can replace it in this directory without changing the publishing flow.
